# Arthsangh – Finance Collective

## 📌 Project Overview

Arthsangh – Finance Collective is a finance management application developed to provide an organized platform for managing financial information and activities.

The project is developed using Java, Spring Boot and MySQL, following a structured backend architecture.

## 🚀 Features

- User Management
- Finance Data Management
- Secure REST APIs
- Database Integration
- CRUD Operations
- Backend Validation
- Exception Handling
- API-based Communication

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API

## 🏗️ Architecture

The application follows a layered architecture:

- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer
- Database Layer

## 🗄️ Database

MySQL is used as the database for storing and managing application data.

## ⚙️ How to Run

1. Install Java JDK.
2. Install MySQL.
3. Clone the repository.
4. Open the project in IntelliJ IDEA or Eclipse.
5. Configure MySQL database details in `application.properties`.
6. Update Maven dependencies.
7. Run the Spring Boot application.
8. Test the APIs using Postman.
